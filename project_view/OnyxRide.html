OnyxRide – Car Rental Inventory Web System

A Web-Based Solution for Efficient Car Rental Management

A comprehensive web-based inventory management system designed specifically for car rental businesses, featuring role-based access control, real-time tracking, and intuitive data visualization.

This page showcases the full UI/UX as a visual walkthrough due to free hosting limitations. All key features are explained below.

Project Highlights

OnyxRide represents my capstone project developed during my Software Engineering studies at SMK Negeri 3 Kendal. This robust system addresses the core operational needs of car rental businesses by providing a centralized platform for inventory management, transaction processing, and business analytics.

The application implements a dual-role architecture with distinct interfaces for administrators and management personnel, ensuring appropriate access levels and functionality segregation. Built with PHP and MySQL, OnyxRide delivers a responsive, secure, and efficient solution for modern car rental operations.

Key Features

Role-Based Access Control

Secure authentication system with differentiated interfaces and permissions for administrators and management staff.

Comprehensive Fleet Management

Complete lifecycle tracking of vehicles including acquisition, maintenance, availability, and retirement.

Stakeholder Management

Centralized management of user accounts, customer profiles, and supplier relationships with full CRUD operations.

Business Intelligence

Automated generation of operational reports, financial summaries, and utilization analytics.

Security Framework

Robust authentication system with password encryption and session management for data protection.

Asset Documentation

Visual inventory management with image upload capabilities for vehicle condition tracking.

Compliance Features

Built-in documentation including terms of service, privacy policies, and regulatory compliance pages.

document.addEventListener('DOMContentLoaded', function() {
    // Initialize chart
    const ctx = document.getElementById('borrowingChart').getContext('2d');
    const borrowingChart = new Chart(ctx, {
        type: 'bar',
        data: {
            labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'],
            datasets: [{
                label: 'Borrowing Activity',
                data: [5, 8, 12, 6, 9, 15, 7, 10, 8, 11, 13, 9],
                backgroundColor: '#4361ee',
                borderColor: '#3f37c9',
                borderWidth: 1,
                borderRadius: 6
            }]
        },
        options: {
            responsive: true,
            maintainAspectRatio: false,
            scales: {
                y: {
                    beginAtZero: true,
                    grid: {
                        color: 'rgba(0, 0, 0, 0.05)'
                    }
                },
                x: {
                    grid: {
                        display: false
                    }
                }
            },
            plugins: {
                legend: {
                    display: false
                },
                tooltip: {
                    backgroundColor: '#333',
                    titleFont: {
                        family: 'Poppins',
                        size: 14
                    },
                    bodyFont: {
                        family: 'Poppins',
                        size: 12
                    }
                }
            }
        }
    });

    const elements = document.querySelectorAll('.summary-card, .profile-card, .chart-section');
    elements.forEach((el, index) => {
        el.style.opacity = '0';
        setTimeout(() => {
            el.style.transition = 'opacity 0.5s ease, transform 0.5s ease';
            el.style.opacity = '1';
        }, 100 * index);
    });
});
