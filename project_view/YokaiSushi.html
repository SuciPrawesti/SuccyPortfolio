YokaiSushi – Authentic Japanese Sushi Experience

Traditional • Artisanal • Modern

An elegant website design for a Japanese sushi restaurant featuring cherry blossom decorations, leaf motifs, and a warm color palette with Japanese-inspired typography, combining traditional aesthetics with modern web design.

This page showcases the system's features and code implementation. The actual application is a Windows Forms desktop application.

Project Overview

YokaiSushi is a modern website for an authentic Japanese sushi restaurant. The design combines traditional Japanese elements like cherry blossoms and leaf motifs with contemporary web aesthetics, using a warm color palette of #3D2100 for main titles and #F6911E for secondary headings, set against soft gradient backgrounds of #E6CCAA and #F8EFE3.

Designed in Figma with a mobile-first approach, the website features five main sections: Home, About, Menu, Testimonials, and Contact. Each section is carefully crafted to showcase the restaurant's atmosphere while maintaining excellent usability and visual appeal.

Key Features

Home Section

Elegant hero section with high-quality sushi imagery, call-to-action buttons, and a brief introduction to the restaurant's philosophy and specialties.

About Us

Story of the restaurant, chef's profile, and our commitment to authentic Japanese sushi traditions using the freshest ingredients and traditional techniques.

Interactive Menu

Beautifully presented sushi menu with categories, high-quality food photography, detailed descriptions, and dietary indicators for each item.

Customer Testimonials

Carousel of authentic customer reviews with ratings and photos, building trust and showcasing the dining experience.

Contact & Location

Interactive map, contact form, opening hours, and online reservation system for convenient booking.

Mobile Responsive

Fully responsive design that adapts perfectly to all devices from smartphones to desktop computers.

Japanese Aesthetics

Incorporates traditional Japanese design elements like cherry blossoms, leaf motifs, and minimalist layouts with modern web design principles.

Design Highlights

Visual Elements
  • Color Scheme: Warm and inviting palette featuring #3D2100 for main titles, #F6911E for secondary headings, and soft gradient backgrounds of #E6CCAA to #F8EFE3
  • Japanese Motifs: Cherry blossom branches, leaf decorations, and subtle Japanese wave patterns throughout the design

  • Navigation: Clean, intuitive navigation with five main sections (Home, About, Menu, Testimonials, Contact)
