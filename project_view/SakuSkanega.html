SakuSkanega - Class Treasury Management System

Streamlining Class Financial Management

A comprehensive web-based solution designed to simplify class treasury management, featuring secure authentication, financial tracking, and intuitive reporting for class treasurers.

This page showcases the full UI/UX as a visual walkthrough due to free hosting limitations. All key features are explained below.

Project Overview

SakuSkanega is a specialized web application developed as a school project to address the challenges of managing class finances. This system provides class treasurers with a centralized platform for tracking class dues, recording expenses, and generating financial reports.

The application implements a secure login system with a dedicated interface for treasurers, ensuring proper access control and data protection. Built with PHP and MySQL, SakuSkanega offers a responsive, user-friendly solution for modern class financial management.

Key Features

Secure Authentication

Protected login system ensuring only authorized treasurers can access financial data and management features.

Student Management

Complete tracking of class members including payment status, dues history, and contact information.

Payment Tracking

Comprehensive recording of class dues payments with date stamps, amount verification, and receipt generation.

Financial Analytics

Visual dashboard displaying class fund status, payment completion rates, and expense breakdowns.

Expense Management

Detailed recording of class expenditures with categorization, approval tracking, and documentation.

Report Generation

Automated creation of financial statements, payment summaries, and expense reports for transparency.

Payment Reminders

Built-in notification system to track overdue payments and send reminders to students.
