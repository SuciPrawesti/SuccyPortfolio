YouNance – Savings Management System

Modern Interface • Secure Transactions

A comprehensive savings management system built with C# Windows Forms and MySQL, designed to streamline banking operations with role-based access control.

This page showcases the system's features and code implementation. The actual application is a Windows Forms desktop application.

Project Overview

YouNance is a desktop-based savings management system developed as part of my software engineering education. The system provides a complete solution for managing customer savings accounts, teller operations, deposits, withdrawals, and reporting.

Built with C# Windows Forms and MySQL database, the application features a modern UI designed with Guna UI components. The system implements secure login authentication, role-based access control (for tellers and administrators), and comprehensive transaction tracking.

Key Features

Secure Login System

Role-based authentication with separate interfaces for tellers and administrators, featuring password protection.

Customer Management

Comprehensive customer account management including account opening, updates, and account status tracking.

Teller Management

Administrator tools for managing teller accounts, permissions, and access levels within the system.

Deposit Processing

Secure deposit transactions with automatic balance updates and receipt generation for customers.

Withdrawal Processing

Controlled withdrawal system with balance verification and transaction recording.

Transaction Reports

Detailed reporting for deposits and withdrawals with filtering options by date, teller, or customer.

Dashboard Analytics

Visual dashboard displaying key metrics including total deposits, withdrawals, and customer growth.

    public partial class frmLogin : Form
    {
        public frmLogin()
        {
            InitializeComponent();
        }

        private void btnLogin_Click(object sender, EventArgs e)
        {
            string username = guna2TextBoxUsername.Text;
            string password = guna2TextBoxPassword.Text;

            using (var conn = Koneksi.GetConnection())
            {
                try
                {
                    conn.Open();
                    string query = "SELECT * FROM t_kasir WHERE nama_pengguna=@username AND sandi=@password";
                    MySqlCommand cmd = new MySqlCommand(query, conn);
                    cmd.Parameters.AddWithValue("@username", username);
                    cmd.Parameters.AddWithValue("@password", password);

                    MySqlDataReader reader = cmd.ExecuteReader();
                    if (reader.Read())
                    {
                        this.Hide();
                        frmMenuUtama menuUtama = new frmMenuUtama();
                        menuUtama.Show();
                    }
                    else
                    {
                        MessageBox.Show("Username or password is incorrect!");
                    }
                }
                catch (Exception ex)
                {
                    MessageBox.Show("Error: " + ex.Message);
                }
            }
        }

        private void btnExit_Click(object sender, EventArgs e)
        {
            Application.Exit();
        }
    }

-- Database table structure for tellers (kasir)
CREATE TABLE `t_kasir` (
  `id_kasir` int NOT NULL AUTO_INCREMENT,
  `nama_kasir` varchar(30) DEFAULT NULL,
  `nama_pengguna` varchar(30) DEFAULT NULL,
  `sandi` varchar(30) DEFAULT NULL,
  PRIMARY KEY (`id_kasir`),
  UNIQUE KEY `nama_pengguna` (`nama_pengguna`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
